兩支工具的規格書 開源 · 給 AI 讀 Mac

我自己天天在用的兩支工具，開源了，但沒有放程式碼——放的是讓你的 AI 照著蓋的施工圖。分階段的施工順序、每個介面的規格、二十幾個不會噴錯的地雷，還有每一步該怎麼驗收。整包丟給你的 AI，說「照著蓋」，它會蓋出屬於你的那一版：你的快捷鍵、你的聲音、你的辭典。

  • Aloud　選單列朗讀窗：任何 App 選字右鍵就唸給你聽，逐句串流所以首字延遲不到半秒、跟文章多長無關，唸到哪句亮哪句
  • WhisperBar　本機語音輸入：按一下 Fn 開始講、再按一下就貼進游標；轉譯全程在自己機器上跑，錄音不上傳
  • 為什麼不給程式碼：這兩支跟我的機器、我的辭典、我的快捷鍵綁太緊，原封不動給你也裝不起來。而真正花時間的是那些不會報錯的坑，寫成文件比程式碼耐久
  • 每個 repo 五份文件：施工順序／介面契約／地雷清單／驗收條件／給 agent 的入口指示

Credits 片尾名單 網頁 · 資料庫

廣告沒有片尾名單，所以誰拍的、誰剪的、誰調的光，從來沒有地方被記下來。這裡把公開發佈的名單全部收進來，每一筆都附原始連結可以自己點回去核對。找攝影師、找剪輯師、找製作團隊用的。

  • 一萬三千多支作品、兩萬七千位工作人員，全部來自各家自己公開的名單
  • 關聯星圖：左邊是人、右邊是作品，點誰誰就變中心，一路點下去找班底
  • 類型、地區（北中南東）、日期／相關度排序，卡片與圖牆兩種看法
  • 搜尋不斷詞：打「芒果」出水果類的廣告，打不到也會給最接近的，不交白卷
  • 怎麼讓自己的名單被機器（跟 AI）讀到，另附一頁格式說明與產生器

濾鏡工坊 網頁 · 免安裝

把照片變成孔版印刷（Risograph）質感：先把顏色減成兩三支油墨，每支各自角度過網，再一層層疊印回紙上。做法是拿實體孔版印刷品量出來的——網點角度、紙色、分色版都照量測值反推，不是套色調。

  • 油墨自己選（一到三支）＋紙色可調；網點間距、硬度、套印偏移、油墨濃度全是拉桿即時重算
  • 邊緣四邊各自控制：孔版粗邊、撕毛邊（會露紙芯的那種）、羽化，上下左右可以各給一種
  • 輸出 PNG 用照片原始解析度重算，質感跟預覽一致

RHEO Mac · 開源 1.0

流動扭曲編輯器——照片或影片放進來，用滑鼠在畫面上抹，效果沿著筆跡長出來；放開手，它自己慢慢流回去。⌘S 截當下那格、⌘R 把整段流動錄成影片。輸出的永遠是畫布本身，檔案裡沒有介面——抹出來的東西直接當素材進剪輯。

  • 21 種效果（鏡片／液化／場域／玻璃感／慢快門／拖曳流動）共用一張位移場，全部會流回來
  • 影片播放中即時抹；回彈快慢可調，調到 0 就凍住當定格作品
  • 畫布＝來源解析度（上限 4096），輸出不縮圖

唸書機 開源 · 管線 跟讀器 · PWA

把英文書翻成台灣口語中文、唸成有聲書，包成手機上「邊聽邊看字」的跟讀器。翻譯與濃縮交給你手上的 AI agent，語音走免費的 edge-tts——整條管線零成本。附《沉思錄》示範書：同一章三種深度（速讀／精讀／英中對照＋生字講解），聽完再決定自己的書要翻到什麼程度。

  • README 是寫給 agent 的公式：repo 丟給你的 AI，說「照 README 把某本書做成跟讀器」就能跑
  • 跟讀器加入主畫面即成 App：逐字亮字、逐章離線、長按畫重點做筆記、跨裝置同步（自架）
  • 對照版含生字卡：字義、例句、為什麼原文用這個字，生字點了就發音（正常＋慢速）
