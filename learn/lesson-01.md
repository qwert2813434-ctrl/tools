# AI Agent 入門基礎：我怎麼做的｜第 1 課　給 AI 一個資料夾

網址：https://tools.arminkao.com/learn/lesson-01.html

> 這一課做完，你會：裝好 Claude 桌面版，讓它在你電腦上建出第一個檔案。
> 需要：一台 Mac 或 Windows 電腦、Claude 付費方案（Pro 以上，免費方案不能用 Code）。

## 這一課帶走

- 一個「AI 工作夾」
- 一句話：**新手選「手動」，看清楚再按「允許一次」。**
- 習慣：想自己動手前，先叫它做。

## 給 AI Agent：照這段做

把這頁網址丟給你的 AI，說「照這頁幫我做」。

你是使用者的 AI agent，使用者剛裝好 Claude 桌面版、在 Code 分頁選了一個空資料夾。

- **準備**：使用者已選好資料夾（例：「AI 工作夾」），模式是「手動」。
- **步驟**：
  1. 只在使用者選的這個資料夾裡動作，不碰資料夾外的檔案。
  2. 建立 `第一天.md`，內容：今天的日期＋一句給使用者的話。寫檔前先說要寫什麼，等使用者按允許。
  3. 用系統指令打開這個資料夾給使用者看（執行前同樣先問）。
- **完成**：資料夾裡有 `第一天.md`，使用者在 Finder／檔案總管看到它。
- **不要**：開「略過權限確認」；動資料夾以外的東西；一次做多件事不說明。
