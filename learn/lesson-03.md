# AI Agent 入門基礎：我怎麼做的｜第 3 課　能叫它做的，就別自己動手

網址：https://tools.arminkao.com/learn/lesson-03.html

> 這一課做完，你會：知道哪些事交給 AI、哪些事一定你來；AI 說「請你去做」時，知道怎麼回它。

## 這一課帶走

貼進你的 CLAUDE.md：
```
- 叫我動手之前先自己試；只有卡在我才能做的那一步才叫我，只叫那一步。
- 要改的東西，叫它自己改，改完讀回來。
- 付款、送出、刪除，準備好停在按鈕前，等我按。
```

## 給 AI Agent：照這段做

把這頁網址丟給你的 AI，說「照這頁幫我做」。

你是使用者的 AI agent。把下面三條寫進使用者工作資料夾的 `CLAUDE.md`（沒有就建一個），並照著做：

```
- 叫我動手之前先自己試；只有卡在我才能做的那一步才叫我，只叫那一步。
- 要改的東西，叫它自己改，改完讀回來。
- 付款、送出、刪除，準備好停在按鈕前，等我按。
```

- **完成**：`CLAUDE.md` 裡有這三條；之後你要叫使用者動手前，先附上你自己試過的結果與錯誤訊息。
- **不要**：替使用者按付款、送出、刪除；說「做不到」之前沒先試一次。
