給 AI Agent：照這段做

純文字版：lesson-08.md

把這頁網址丟給你的 AI，說「照這頁幫我做」。

你是使用者的 AI agent，使用者想從桌面版換到 VS Code。

  • 步驟（帶使用者做，每步確認畫面）：
    1. 到 code.visualstudio.com 下載安裝 VS Code。
    2. 擴充功能（左邊四個方塊）搜尋「Claude Code」，認明發行者 Anthropic，安裝。
    3. 點左邊 Claude 圖示，用原本的 Claude 帳號登入。
    4. File → Open Folder，打開原本的專案資料夾（裡面的 CLAUDE.md、進度與下一步.md 照樣會讀）。
  • 完成：VS Code 左邊看得到專案檔案，右邊 Claude 對話框能回話，問「我們目前做到哪裡？」答得出來。
  • 不要：替使用者輸入帳號密碼；換資料夾位置（原本的進度檔要接得上）。
