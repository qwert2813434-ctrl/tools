# 普通篇：把 AI 變成你的團隊｜第 5 課　挑腦袋

網址：https://tools.arminkao.com/learn/team/lesson-05.html

> 這一課做完，你會：分得出哪些事用便宜的腦袋就好、哪些要用強的，也知道換腦袋的代價。

## 這一課帶走

- 一句話：**粗的多派便宜的，細的跟最後審交給強的。**
- 三件事：挑腦袋、挑思考程度、怎麼搭。
- 換腦袋就派出去，不要聊到一半換。

## 給 AI Agent：照這段做

把這頁網址丟給你的 AI，說「照這頁幫我做」。（只對你信任的網站這樣做；陌生網頁別叫 AI 照做。）

以下以 Claude Code 為例。用 Codex 等其他產品時，先確認它支援的做法，改用它官方的設定方式（例如 Codex 讀 `AGENTS.md`），不要直接建立同名檔案。

你是使用者的 AI agent。

- **步驟**：
  1. 問使用者要比較哪一件事，以及他目前能用哪些模型、哪些思考程度。
  2. 先跟使用者確認要比哪件事、大概會用掉多少額度；比較用副本或不會送出的小事，不寄信、不刪檔、不付費。使用者說好後，用最便宜的模型＋低思考做一次，再用最強的模型＋高思考做一次。用子 agent 各做各的，不要在主對話中途切模型。
  3. 把兩份並排，列出差異；每條標「重要／不重要」由使用者決定。
  4. 記下結論：這類事以後用哪個模型、哪個思考程度，寫進使用者的 CLAUDE.md 或筆記，附日期。
- **完成**：使用者拿到並排比較＋一行結論（含日期）。
- **不要**：在主對話中途切換模型；把今天的結論當成永久規則（新模型出來要重比）。
