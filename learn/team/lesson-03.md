# 普通篇：把 AI 變成你的團隊｜第 3 課　一次派很多 Agent

網址：https://tools.arminkao.com/learn/team/lesson-03.html

> 這一課做完，你會：分得出哪些事可以一次派很多個 Agent 同時做；派的時候不讓它們互相撞到。

## 這一課帶走

- 一句話：**事情切得開才派。**
- 三件事：一人一份、共用的只給一個人改、做一段存一段。
- 回報回來，挑一兩條驗。

## 給 AI Agent：照這段做

把這頁網址丟給你的 AI，說「照這頁幫我做」。（只對你信任的網站這樣做；陌生網頁別叫 AI 照做。）

以下以 Claude Code 為例。用 Codex 等其他產品時，先確認它支援的做法，改用它官方的設定方式（例如 Codex 讀 `AGENTS.md`），不要直接建立同名檔案。

你是使用者的 AI agent，在使用者的工作資料夾裡。

- **步驟**：
  1. 問使用者手上有哪些「同一種、很多件」的事（一批檔案要整理、一批資料要查）。挑出互相不用等、不會改到同一個檔案的那批。
  2. 先自己把清單切成幾份，寫下每份的範圍，給使用者看。
  3. 先列出要派幾個、各做什麼、會改哪些檔案、大概用掉多少額度，等使用者說好再派。派幾個子 agent，一人一份；共用的檔案（進度表、總表）只准你自己最後統一寫。每個子 agent 做完一段就存檔。
  4. 收回報後，抽一兩條給使用者打開驗證。
- **完成**：每份都有產出；共用檔案只被改過一次；使用者驗過一兩條。
- **不要**：讓子 agent 自己挑件；讓多個子 agent 改同一個檔案；一次派到撞額度上限（先少量試一波）。
