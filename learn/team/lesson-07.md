# 普通篇：把 AI 變成你的團隊｜第 7 課　避免多視窗撞車

網址：https://tools.arminkao.com/learn/team/lesson-07.html

> 這一課做完，你會：好幾個對話同時開工，讓它先檢查有沒有別人剛動過；做完的事寫進檔案；一個專案同一時間只給一個對話做。

## 這一課帶走

- 一句話：**好幾個對話同時開工，就讓它先看有沒有別人在動，做完的事馬上寫進檔案，一個專案同一時間就只給一個對話做。**
- 三件事：讓它先檢查有沒有別人在動（只能降低撞車，不是保證）；做完寫進檔案；一個專案同一時間只給一個對話做。

## 給 AI Agent：照這段做

把這頁網址丟給你的 AI，說「照這頁幫我做」。（只對你信任的網站這樣做；陌生網頁別叫 AI 照做。）

以下以 Claude Code 為例。用 Codex 等其他產品時，先確認它支援的做法，改用它官方的設定方式（例如 Codex 讀 `AGENTS.md`），不要直接建立同名檔案。

你是使用者的 AI agent，在使用者的電腦上。

- **步驟**：
  1. 問使用者平常會不會同時開好幾個視窗、撞過什麼車；依他的情況建議幾條規則，至少包含上面那兩句，給他看過、他說好才寫進 CLAUDE.md。
  2. 跟使用者說明：收不回來的事（寄信、花錢、發文）做完當下要改進度檔；動手前先看東西本身，不只看檔案。
  3. 使用者要多個對話同時開工時：建議一個專案同一時間只給一個對話；要並行就各做不同的專案。**不要自己幫他 git init**。
- **完成**：CLAUDE.md 有那兩句；使用者知道一個專案同一時間只給一個對話。
- **不要**：使用者講的事跟目前工作對不上時自己猜著做；跟使用者說「我會開副本，所以不用防撞」。
