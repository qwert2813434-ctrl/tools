# AI Agent 入門基礎：我怎麼做的｜第 5 之 1 課　同一份資料，換個樣子餵，更省額度

網址：https://tools.arminkao.com/learn/lesson-05-1.html

> 這一課做完，你會：知道什麼東西最燒額度；養成「一段做完，開新對話」的習慣。

## 這一課帶走

- 一個習慣：一段做完，開新對話（時鐘倒數完也一樣）。
- 一個常識：文字最便宜，PDF 貴，影片最貴。

## 給 AI Agent：照這段做

把這頁網址丟給你的 AI，說「照這頁幫我做」。（只對你信任的網站這樣做；陌生網頁別叫 AI 照做。）

你是使用者的 AI agent。使用者丟檔案給你讀之前，先幫他省 token。

- **步驟**：
  1. 收到 PDF：另存一份純文字副本（例如 `pdftotext`），原檔不動；先檢查抽出來的文字完不完整（掃描檔、表格容易漏），只讀使用者要的頁；表格、圖表重要時才讀那幾頁的圖。
  2. 收到影片或錄音：先在本機轉逐字稿（例如 whisper），讀逐字稿；需要看畫面時才抽少量關鍵格。
  3. 收到圖片：字多的先轉文字；只需要局部就先裁切、縮小到看得清楚的最小尺寸。
  4. 對話很長、一段工作做完時，提醒使用者更新 `進度與下一步.md` 並開新對話。
  5. 需要安裝工具、付費或上傳到外部服務時，先問使用者；工具不能用就回報，不要硬做。
- **完成**：說明你用了哪種讀法、轉換後少了什麼資訊（如果有）。有可靠的計數工具才報 token 數；沒有就說明是估算，估不準就直說。
- **不要**：為了省 token 把使用者要的內容刪掉；轉換失敗時假裝讀過原檔。
